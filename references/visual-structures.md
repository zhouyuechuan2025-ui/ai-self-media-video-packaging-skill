# Visual structures

| Structure | Best use | Default safe zone |
|---|---|---|
| impact-question | direct question or sharp tension | approved full-screen hook |
| contrarian-stamp | correction or counterintuitive conclusion | left/right editorial lane |
| gradient-keyword | one dominant term | left/right transparent lane |
| split-conflict | two opposing states | full |
| three-beat-hook | result, tension, promise | approved full-screen hook |
| side-insight-card | supporting explanation beside a face | left |
| dual-concept | two related concepts | full |
| keyword-relay | short chain of concepts | left/right transparent lane |
| adaptive-steps | ordered execution | right |
| signal-route | flow, system, or connection | full |
| state-switch | before/after state change | right |
| chapter-timeline | progression across a section | full |
| evidence-pip | supporting proof beside source footage | left |
| evidence-takeover | proof requiring focused reading | full |
| metric-counter | one source-backed or attributed number | left/right transparent lane |
| before-after | clear comparison | full |
| capability-matrix | multiple capabilities or dimensions | full |
| completion-rail | conclusion and next action | left/right edge or closing full-screen |

Do not select a structure solely for variety. The spoken logic, protected screen region, and evidence status decide the structure.

For center-presenter footage, ordinary structures keep x=35-65% clear and use the left x=6-32% or right x=68-94% lane. Full-screen structures are limited to hook, bridge, evidence, payoff, and CTA roles. Videos over 30 seconds use at least four semantic palettes and five structures, without adjacent structure/palette repetition.
