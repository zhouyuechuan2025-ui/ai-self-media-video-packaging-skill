# Ten semantic visual structures

The content contract determines the layout. A palette change does not create a new structure.

| Structure | Required content | Use when | Avoid when | Default treatment |
|---|---|---|---|---|
| `editorial-dual-rail` | kicker, headline, left items, right items, takeaway | the speaker contrasts two categories or gives parallel lists | there is only one claim | two framed side rails, transparent center |
| `thesis-and-proof` | thesis, reason, optional source | one claim needs explanation or attribution | there is a real screenshot needing focused reading | one thesis rail plus one separately bordered proof rail |
| `bidirectional-flow` | left/right labels, forward action, optional return action, result | human/AI, input/output, generate/review loops | the process only moves forward | two anchored nodes with distinct forward and return routes |
| `command-palette` | title, two to five actions, result state | literal operations, checks, approvals, commands | conceptual benefits or broad positioning | focused action rows with final state stamp |
| `four-stage-pipeline` | title, three or four stages, optional output | an ordered production or delivery process | sequence is unclear or has more than four phases | connected persistent stage cards |
| `before-after-scrub` | before, after, criterion, optional delta | exactly two comparable states | multiple categories or unsupported performance claims | deterministic two-state scrub divider |
| `evidence-panel` | evidence asset, caption, source, interpretation | an approved primary source must be read | no real source asset is available | source image dominates; interpretation is secondary |
| `metric-odometer` | one to three metrics with evidence status | a number is sourced, owner-confirmed, or explicitly estimated | a number has no attribution | large odometer plus visible evidence status |
| `signal-route` | three to five nodes, route label, optional failure node, result | a system, dependency, or information path is explained | the sequence is merely a list | traced SVG route with persistent nodes |
| `semantic-doodle` | subject, action, outcome, accent, optional annotation | an abstract action or transformation benefits from a metaphor | the drawing would be treated as proof | integrated line drawing plus action and outcome layers |

## Placement contract

- Ordinary copy uses left x=5%–32% or right x=68%–95%.
- Center x=35%–65% stays clear for the presenter unless a short approved full-screen moment intentionally dims the source.
- The bottom 18% contains no critical copy.
- Full-screen structures are reserved for hooks, bridges, evidence, payoff, CTA, or structures whose meaning requires a system-wide view.
- For videos over 30 seconds, use at least eight semantically justified structures. Never force a structure solely to increase the count.
