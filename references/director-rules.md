# Director and evidence rules

- The opening must establish one readable tension or result within three seconds. Do not stack unreadable micro-cards.
- Prefer short visual states that follow semantic changes in speech. Do not animate every noun.
- Protect faces, products, source subtitles, and platform UI. Use left/right placement according to the source frame.
- Use structure changes to mark changes in reasoning: question, contrast, steps, route, proof, metric, comparison, or close.
- A number spoken in the source remains a speaker claim unless independently verified. Label estimates and personal tests instead of upgrading them to general facts.
- Evidence structures require a real screenshot or document, a readable source label, and a locally permitted asset.
- A line illustration explains; it does not prove. Keep it abstract, light, and subordinate to the spoken point.
- Preserve the source edit and audio by default. A browser-compatible proxy may be created without cuts when the source codec cannot be decoded by Chromium.
