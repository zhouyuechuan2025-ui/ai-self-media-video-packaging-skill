# Contributing

1. Add a failing test for each behavior change.
2. Keep animations frame-driven and deterministic.
3. Do not add private media or unverifiable claims.
4. Run `npm run verify:all` before opening a pull request.
5. Include a reproducible example when adding a visual structure.

By contributing, you confirm that your contribution may be distributed under
